# Coolara — Pre-event starter

This is a generic Next.js starter prepared before the official build window.
It deliberately contains no Coolara-specific user interface, database schema,
synthetic data, API integration, AI prompt, calculation logic, or deployment.

Before the event, confirm that the official rules permit a generic framework
scaffold. The official rules always take precedence.

## During the build window

1. Create a commit or tag marking the official start time.
2. Build all application-specific functionality after that point.
3. Keep API keys in environment variables only.
4. Complete `PRE_EXISTING_DISCLOSURE.md` honestly before submission.
